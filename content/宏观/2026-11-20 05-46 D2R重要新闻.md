## 七、交易备忘（非投资建议）

| 关注点 | 含义（备忘） |
|---|---|
| **峰会"增供"承诺 vs 实际** | 三方承诺增加燃料供应，但彭博与 IEA 均不认账。**供给端没有新增量**，油价的方向更取决于伊朗—霍尔木兹的实际扰动与 OPEC+ 行为，而非峰会措辞。 |
| **霍尔木兹袭击 × 油价下跌** | 地缘溢价与基本面方向背离（袭击升级、油价却因供应过剩下滑）。若袭击造成实际装船中断，价差可能剧烈重估；否则溢价继续被供应压制。 |
| **美联储 12 月加息 + AI 通胀叙事** | 纪要把"AI 资本开支"写进通胀风险，这是新的政策变量：AI 越热 → 越可能加息 → 长久期资产越承压。贵金属已连续四日下跌，实际利率是主导。 |
| **金价 14 个月低点** | 在加息周期中，黄金的避险属性被实际利率压制。除非地缘事件升级为系统性风险，否则反弹需要看到加息预期回落。 |
| **Anthropic IPO 的分配结构** | 机构几乎零配售、散户主导，首日大涨更像是流通盘稀缺而非基本面定价。**解禁与后续增发**是中期压力点（彭博另有专文提示"后续股票很多，或许太多"）。 |
| **英伟达治理风险** | CEO 被罢免 + 穆迪下调展望 + "间谍丑闻"，是**公司特定风险**而非行业需求风险。关注供应链（台积电、三星对华断供）与客户资本开支是否受牵连。 |
| **铜：中国从美国库存抽货** | 这是**实物紧张**的硬信号，与铜价暴跌后的反弹相互印证。若抽库持续，LME/COMEX 价差与溢价结构值得跟踪。 |
| **焦煤三月低点 vs 铜紧张** | 黑色与有色分化：焦煤是供应恢复驱动的下跌，铜是现货紧张驱动的反弹。不宜把"大宗"当成一个同向板块。 |
| **空运运价 2022 年以来最高 + 电路板短缺** | 供应链瓶颈正从"芯片"扩散到"基础电子件 + 运力"。关注电子制造与消费电子的成本传导。 |
| **巴西/法国/墨西哥的汇率压力** | 财政与政治风险正在新兴市场与欧洲外围同时定价。美元在加息 + 避险下偏强，EM 货币承压的结构未变。 |
| **日本：BOJ 开放加息 + 烟草巨额减记** | 日元资产的套利逻辑面临双向风险；企业端已出现俄罗斯资产没收的实际损失案例。 |
